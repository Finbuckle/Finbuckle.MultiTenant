## About MultiTenant

MultiTenant is an open source multi-tenancy library for modern .NET created and maintained by [Finbuckle LLC](https://www.finbuckle.com). It enables tenant resolution, per-tenant app behavior, and per-tenant data isolation.

See [https://www.finbuckle.com/MultiTenant](https://www.finbuckle.com/multitenant) for more details and documentation.

See the [release history](https://www.finbuckle.com/MultiTenant/Docs/History) for all release details.

## Open Source Maintenance Fee

This project participates in the [Open Source Maintenance Fee](https://opensourcemaintenancefee.org). As of November 10,
2026, with the release of .NET 11, MultiTenant v11 and later require the Maintenance Fee for use in revenue-generating
activities. MultiTenant v10 does not require the fee, but users are encouraged to participate voluntarily by
[becoming a Sponsor](https://github.com/sponsors/finbuckle).
